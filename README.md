# RegioJet do Prahy – textová adventúra (4IT107)

Hra podľa nášho GDD. Projekt sa zostavuje cez **Maven** (`pom.xml`).

```
mvn test        # spustí JUnit testy
mvn package     # vytvorí target/regiojet-do-prahy-1.0.jar
```

`resources/svet.txt` – celý obsah hry (lokality, východy, predmety, postavy, úlohy, texty).
